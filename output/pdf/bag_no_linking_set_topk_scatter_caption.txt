Model exclusion probabilities versus observed human exclusion rates in the bag context. Each panel contains the same 30 ordered trigger-query pairs, using saved corrected predictions. Both axes span 0 to 1 on the same linear scale. The dashed equality line marks p = y; points above it have model probabilities below observed human rates. Marker area is proportional to the number of pairs at identical coordinates, using the same size scale in both panels. Coordinates are not jittered. Means weight each of the 30 pairs equally. Human rates are sample estimates; equality here describes agreement with those observed rates.
