Context-level changes in exclusion correlation after applying Set Top-K, for all 16 contexts (480 ordered trigger-query pairs). Points show Set Top-K minus No linking for (A) Spearman and (B) Pearson exclusion correlations, each calculated across 30 equally weighted ordered pairs. Blue diamonds identify perfect model-human word-ranking agreement (bakery and fridge); blue circles identify the five contexts with word-ranking Spearman = .943 (rounded); gray circles identify the nine contexts with word-ranking Spearman <= .9. Contexts are ordered alphabetically. Positive values favor Set Top-K. Both panels use identical horizontal limits. Values are descriptive point differences, not significance tests or confidence intervals; predictions are unchanged from the corrected held-out evaluation.
